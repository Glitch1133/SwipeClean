\# SwipeClean



SwipeClean is an Android storage cleaner that makes reviewing files quick and simple using a swipe-based interface.



\## Features



\- Swipe right to keep

\- Swipe left to remove

\- Everything cleanup mode

\- Photos

\- Videos

\- Screenshots

\- Audio

\- Downloads

\- Documents

\- Other files

\- Installed apps

\- Fullscreen media previews

\- Video and audio playback

\- PDF and text previews

\- File previews

\- Undo

\- Trash review system

\- Permanent file deletion with confirmation

\- App uninstall confirmation

\- Sort by file size and date

\- App Last Used sorting

\- Light mode

\- Dark mode



\## Trash \& Deletion



Items swiped left are first placed into SwipeClean's Trash.



Users can review and restore items before permanently removing them.



Permanent deletion cannot be undone once confirmed.



Android's system confirmation is used where required for media deletion and app uninstalling.



\## Android Access



SwipeClean can only access files and apps that Android allows third-party applications to access.



Protected Android system files and private application data are not accessible.



\## Privacy



SwipeClean performs storage cleanup directly on the user's device.
